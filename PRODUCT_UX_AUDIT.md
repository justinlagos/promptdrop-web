# PromptDrop UX audit

Scope so far: prompt settings, mobile Clean Take controls, the desktop editor, and whether
edits and exports are real. Not yet covered: Takes Library, Script Studio, Meetings, the
mobile tool rail redesign, autosave and undo. Sign-in is not required by decision, so the
brief's account and cross-device sync sections do not apply. Each row was checked against the code and has a test in `tests/ux`.

| Issue | Impact | Root cause | Decision | Verified by |
| --- | --- | --- | --- | --- |
| Font size and scroll speed reset between takes | User re-does setup for every take | `RecordSetupScreen` set speed 142 and font 40 from hardcoded `useState` values on every mount. Nothing was saved anywhere. | Fixed. Last-used values saved to `pd.promptPrefs` on the device and loaded on mount, with range checks. | `prompt-preferences.spec.js`: two real takes, navigation, refresh. Fails when the hardcoded defaults are put back. |
| Font sizes above 40px did nothing | Slider offered 28 to 64 but the prompter capped at 40 | `Math.min(cfg.font, 40)` in the live prompter line styles | Fixed. The prompter uses the chosen size; neighbouring lines scale with it. | Same file. Fails when the cap is put back. |
| Last controls in each Clean Take tool hidden under the Save bar | Could not reach Reset, Saturation, Review removed sections, last Export rows | Save bar was an absolute overlay. The panel's bottom padding meant to clear it was cancelled by a `padding` shorthand in the same style object. | Fixed. Save bar is now a normal row below the panel. | `clean-take-mobile.spec.js`, "scrolled clear" test at 7 sizes. Fails when the overlay is put back. |
| Clean Take controls squeezed out on short phones | 65px of control space at 320x568 | Preview height was 36% of the screen regardless of height | Fixed. Preview height now scales with screen height, minimum 120px. Captions button moved above its explanation text. | `clean-take-mobile.spec.js`, "first control visible" test. Fails when 36vh is put back. |
| No desktop editing interface | Desktop users edited in a phone-width frame | `/app` rendered the phone app in a 460px frame on desktop | Fixed. On desktop the editor takes the full window: large preview, edit map below, tools in a side panel, Save and Export in the header, Space and arrow keys. Same component, state and export code as mobile. Other screens stay in a centred column. | `clean-take-desktop.spec.js` at 1024, 1280 and 1440. Fails when the editor is put back in the column. |
| Exported video was a fraction of a second long | Export looked like it worked but the file was unusable (Chrome) | Browser recordings carry no length, so the video element reported Infinity, the export treated that as 0 and stopped at once | Fixed. The real length is resolved before rendering; export refuses with a clear message if it cannot be found. | `clean-take-edits.spec.js`: exported file length with and without cuts and trim, brightness of an exported frame, and the length of the file the Export button downloads. |
| Whole take marked as one pause, clean length shown as 0:00 | Steady speech would be cut away | Silence threshold was 1.8 times the median loudness, so evenly loud audio sat below its own threshold | Fixed. Threshold now comes from the quietest tenth and the loud level, capped at about a third of the loud level. | Same file: tone, gap, tone finds one pause; steady tone finds none. Fails with the old rule. |
| Saved edits not restored | Reopening a take lost speed, trim, kept pauses and colour settings | Load restored only the pause preset | Fixed. All saved decisions are restored. Desktop shows Unsaved or Saved honestly. | Same file, save then reload then reopen. Fails when the old load is put back. |
| Wording claimed export was not connected | Mistrust; told users colour and captions were not exported when they are | Stale copy | Fixed. | Read in the UI. |
| Long prompter lines cut off inside the drop | Speaker loses words | Four lines of different sizes centred in a fixed-height box with overflow hidden | Not fixed. More visible now that large sizes work. | `prompter-fit.spec.js`, switched off until fixed. |
| Settings do not follow the account | New device starts from defaults | No account-backed preferences store | Not fixed. | `test.fixme` in `prompt-preferences.spec.js`. |
| Stale phone bundle | Fixed code not served | Bundle was built by hand with no script in the repo | Fixed. `npm run build:m`, plus a test that fails when the bundle is stale. | `bundle.spec.js` |
